PHP playground

PHP runs in this page, compiled to WebAssembly: no server runs it. This build has every extension the builder supports.

Try it: change the script, and run it (Ctrl+Enter). Nothing is saved: a reload brings the script back.

How it works

    
    
        
  • 
            The page imports build/php-web.mjs, that the stack of
            the page, in stack.php, builds: PHP 8.5, with every
            extension, intl without the data of ICU.
        
    • 
        
  • 
            Run writes the script in the filesystem of PHP, at
            /tmp/playground.php, and runs it with
            php.runFile().
        
    • 
        
  • What PHP writes, and its exit status, come back to the page.
